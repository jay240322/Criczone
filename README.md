# CricZone 🏏

CricZone is a comprehensive, full-stack live-scoring cricket web application. Built with the MERN stack, it provides real-time match updates, comprehensive stats, and a variety of features tailored for different types of users, from casual fans to platform administrators.

## 🚀 Features

### General Platform Features
* **Live Score Updates:** Provides real-time cricket scores using an automated API.
* **Auto-Refresh:** Scores update instantly and automatically without the need for manual page refreshing.
* **Cricket News and Articles:** Offers the latest updates and exciting articles from the world of cricket.
* **Match Schedules and Analysis:** Includes information on upcoming global tournaments, T20 leagues, and local match schedules.
* **Player and Team Statistics:** Provides detailed information on player stats and team rankings.
* **Match Highlights:** Allows users to view record-breaking performances and final match highlights.
* **Distinctive Branding:** Features a clean, simple text-based logo integrated with a bat and ball (avoiding circular designs) for a sleek, modern aesthetic.

### User-Specific Features
* **Registration and Login:** Secure authentication and access for users and administrators.
* **Personalized Dashboard:** Easy access to relevant content and user-specific data.
* **Favorites Section:** A dedicated area where users can quickly access their selected matches, favorite players, and specific highlights without searching.
* **Profile Management:** Intuitive controls for users to manage and update their personal profiles.

### Administrative Features
* **Content Management:** Tools for admins to easily manage match details, news articles, and highlights.
* **User Management:** Capabilities to oversee, manage, and moderate platform users.
* **Report Generation:** Functionality for administrators to generate various system and analytics reports.

## 💻 Tech Stack

* **Frontend:** React.js, JavaScript, HTML5, CSS3
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## 📂 Repository Structure

The project is organized into two main directories:

* `/frontend`: Contains the React client application and UI components.
* `/backend`: Contains the Node.js/Express server, API routes, and database configuration.
* `cricbuzz_id.txt`: Configuration file used for live data fetching.

## 🛠️ Installation & Setup

### Prerequisites
* [Node.js](https://nodejs.org/) installed
* MongoDB running locally or via a cloud service like MongoDB Atlas

### Quick Start
You can clone the repository, install all dependencies, and start both the backend and frontend servers by copying and running this entire block in your terminal:

```bash
# Author: Jay Patel

# 1. Clone the repository and navigate into it
git clone [https://github.com/jay240322/Criczone.git](https://github.com/jay240322/Criczone.git)
cd Criczone

# 2. Setup and start the Backend (runs in the background)
cd backend
npm install
npm start &

# 3. Setup and start the Frontend
cd ../frontend
npm install
npm start

👨‍💻 Author
Jay Patel
```
